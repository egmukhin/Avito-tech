# ТК для проверки api микросервиса.
---

## test_1.  Создание объявления с валидным телом  

### Шаги:
1. Отправить "POST /api/1/item" с телом:
   - "sellerID" (int)
   - "name" (string)
   - "price" (int)
   - "statistics" {"likes", "viewCount", "contacts"} (int)

### Ожидаемый результат:
- HTTP "200"
- "status": Сохранили объявление - … (здесь указан id айтема)
  
---

## test_2. отсутствие обязательного поля (name)

### Шаги:

- HTTP "400"
